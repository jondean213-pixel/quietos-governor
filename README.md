# QuietOS Governor (DeanWay Labs)

The QuietOS governor core: tier classification, Jon-only approvals,
rate limits, audit log, roam controller, and the two-way Jon
notification channel. Pure Python, no dependencies.

- `quietos/` — the governor package
- `termux_watcher.py` — phone end of the notification bridge (Termux)
- Release asset `quietos-phone-bundle.tar.gz` — the phone-install bundle

Private DeanWay property. Not for sale, not for distribution.
